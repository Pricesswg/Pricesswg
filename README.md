## Featured repositories

### Home Assistant integrations

**[Chronos Scheduler](https://github.com/Pricesswg/Chronos-Scheduler)** — advanced multi-domain scheduler for Home Assistant
HACS custom integration with a dedicated Lovelace card. Manages thermostats, lights, blinds, irrigation, switches, fans, water heaters, mowers, vacuums, scenes, and automations through daily time blocks. Features include linear/radial/list timeline editor with drag-and-drop, conditional weather rules (IF/THEN on temperature, rain, wind, UV, sun position), 7-day week view, recurring yearly date ranges, sunrise/sunset anchors, scene and automation schedules with multi-select, and per-block device subsets. UI available in Italian, English, French, and German.

### Home Assistant blueprints

**[Sonoff ORB Buttons](https://github.com/Pricesswg/Sonoff-ORB-Home-Assistant-blueprint)** — full customization of all 16 button actions (single, double, triple, long press across 4 buttons) of the SONOFF ORB controller. Each event maps to any Home Assistant action sequence, configurable from the UI without YAML.

**[ThirdReality Keyboard MK1](https://github.com/Pricesswg/Thirdreality-Keyboard-MK1-Blueprint-automation)** — pilot the 12 Matter buttons on top of the ThirdReality MK1 keyboard. Select the button event and define the action variables to trigger.
