## Featured projects

### [Chronos Scheduler](https://github.com/Pricesswg/Chronos-Scheduler)

Advanced multi-domain scheduler for Home Assistant, distributed as a HACS custom integration with its own Lovelace interface.

Chronos manages thermostats, air conditioners, lights, blinds, irrigation systems, switches, fans, water heaters, robotic mowers, vacuums, alarms, scenes, automations, helpers, and generic Home Assistant services.

Main features include:

* linear, radial, and list timeline editors with drag-and-drop
* daily and weekly scheduling
* sunrise and sunset anchors
* recurring yearly date ranges
* conditional IF/THEN weather and sensor rules
* reusable rules shared across multiple schedules
* local weather-station sensor overrides
* scene, automation, and generic service scheduling
* per-block device subsets and advanced device parameters
* execution history and debugging tools
* JSON import and export
* offline-device recovery
* restart-safe automatic switch-off timers
* automatic recovery of missed valve closures and switch-off commands
* multilingual interface

### [DCS Civil Mission Template](https://github.com/Pricesswg/DCS-Civil-Mission-Template)

Modular native-Lua framework for civil and emergency missions in DCS World, built without MOOSE, MIST, or CTLD.

It includes:

* wildfire detection and firefighting
* helicopter water operations
* C-130 retardant drops
* mountain and maritime search and rescue
* MedEvac and battlefield CASEVAC
* rescue vessels and hospital ships
* police chases and SWAT operations
* tiered cargo transport and supply airdrops
* infrastructure reconnaissance
* VIP transport
* media coverage missions
* dynamic severity and scoring systems
* procedural event generation
* game-master controls through F10 map markers
* session reports and a Python-based cross-session leaderboard

The project includes modular source files, a generated single-file build, Mission Editor documentation, player briefings, a game-master handbook, feasibility analysis, and build tools.

The framework is structurally complete, syntax-checked, and smoke-tested against a mock DCS scripting API. In-game validation is currently in progress.

### [104 WW Training Script](https://github.com/Pricesswg/104-WW-Training-Script)

Collection of standalone native-Lua training modules for DCS World.

The scripts can be loaded independently and do not require MOOSE, MIST, or CTLD.

Available systems include:

* bombing and weapons training ranges
* dogfight and BVR arenas
* dynamically scaled air-combat scenarios
* SEAD training against radar, infrared, and AAA threats
* scramble and interception training
* Ground Controlled Approach training
* carrier operations
* aerial refuelling
* configurable UAV and ground JTAC support
* dynamically configurable laser codes and radio frequencies

### Home Assistant blueprints

#### [Sonoff ORB Buttons](https://github.com/Pricesswg/Sonoff-ORB-Home-Assistant-blueprint)

Home Assistant blueprint providing full customization of all 16 SONOFF ORB button events.

Each single, double, triple, or long press can trigger any Home Assistant action sequence directly from the interface, without manually writing YAML.

#### [ThirdReality Keyboard MK1](https://github.com/Pricesswg/Thirdreality-Keyboard-MK1-Blueprint-automation)

Home Assistant automation blueprint for the 12 Matter buttons integrated into the ThirdReality MK1 keyboard.

Each button can be assigned to custom Home Assistant actions and automation sequences.
